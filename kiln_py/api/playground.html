Quickstart

curl

curl -X POST http://localhost:8420/v1/completions \
  -H "Content-Type: application/json" \
  -d '{"prompt": "hello", "max_tokens": 8}'

Python

import requests
r = requests.post("http://localhost:8420/v1/completions",
                   json={"prompt": "hello", "max_tokens": 8})
print(r.json()["choices"][0]["text"])

JavaScript

const r = await fetch("http://localhost:8420/v1/completions", {
  method: "POST",
  headers: {"Content-Type": "application/json"},
  body: JSON.stringify({prompt: "hello", max_tokens: 8}),
});
console.log((await r.json()).choices[0].text);
